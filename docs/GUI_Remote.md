# DisplayHDR GUI 遙控器

## 啟動

Client ZIP 完整解壓後雙擊 `StartDisplayHDRClient.cmd`，不需安裝 Python 或 Qt。
待測系統使用同批新版 Host ZIP，執行 `StartDisplayHDR.cmd`，看到 READY 後，在 Client 填入 Host IP 與連接埠（預設 8765），按「連線／重新查詢」。

舊版 Host 沒有 `key` 指令，無法使用遙控器按鍵；請一併更新兩端整合包。

## 操作

| 控制 | 原版功能 |
| --- | --- |
| 上／下 | 調整目前測試的子項目或數值，可長按；Shift 加大步進 |
| 左／右、PageUp／PageDown | 前／後測試；Cooldown 等特殊行為沿用原版 |
| 空白鍵 | 切換說明文字 |
| Ctrl | 切換字幕，適用範圍沿用原版 |
| C | Cool-down |
| Home | Start Screen |
| P／Pause | 暫停／繼續，適用範圍沿用原版 |
| A | X-Rite 自動換色 |
| Alt＋Enter／Esc | 切換全螢幕／離開全螢幕 |
| 0–9、Shift＋1–5 | 原版對應測試跳轉；不翻譯測試名稱 |
| ,／. | 棋盤格選擇 |
| −／＋ | X-Rite 換色時間；Shift 沿用原版加大步進 |
| [／] | 參考白階 |

測試選單列出 API catalog 的全部測試，按「切換測試」直接選擇。選單標題使用原版定義，狀態區顯示目前實際標題；動態或隱藏文字時依 API 的 titleSource。

鍵盤操作僅在 GUI 視窗取得焦點時生效；輸入 IP、連接埠或操作測試選單時保留一般輸入行為。Ctrl 搭配其他鍵不會額外切換字幕。
上下按住後約 400 ms 開始重複，之後每 100 ms 嘗試送出一次；尚有請求時略過，不積壓操作。其餘按鍵放開時觸發一次。網路往返時間會限制實際連續調整速度。

## 狀態與斷線

- 每秒查詢 Host；每次操作直接使用 Host 回覆的狀態，核對請求識別值。
- 狀態區包含測試標題、完整設定、程式計算的 Nits、倒數與畫面提交資訊。不是量測值，也不提供遠端畫面預覽。
- 指令或查詢失敗時停用遙控器並停止長按，顯示「狀態未確認」。不自動重送指令；按「連線／重新查詢」讀回狀態後恢復操作。
- 忙碌時的新操作不排隊，狀態列會提示該操作未送出。
- 關閉 Client 不關閉 Host、不還原測試設定；已送出的操作仍可能完成。
- 本地鍵盤仍可使用，狀態以 Host 回讀為準。

命令列 Client 與 Python 自動化介面保留，使用方式見 `Remote_API.md`。
